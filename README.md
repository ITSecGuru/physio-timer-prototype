# Physio Timing Coach
A browser‑based physiotherapy exercise timing assistant with multilingual voice guidance (English, Hindi, Gujarati), adaptive timing, and soothing rest music.  
Designed to help users perform physiotherapy exercises with correct timing, pacing, and rest intervals.

Hosted using GitHub Pages.

---

## 🌟 Features

### 🎧 Intelligent Audio Guidance
- Movement phase: **silent**
- Hold phase: **“Hold” → 2 → 3 → 4…** with optional encouragement
- Repeat announcements:
  - English: “Repeat 3 of 15”
  - Hindi: “दोहराव 3 में से 15”
  - Gujarati: “રીપીટ 3 માંથી 15”
- Between sets:
  - “Take rest for 30 seconds”
  - Hindi: “तीस सेकंड आराम करें”
  - Gujarati: “ત્રીસ સેકન્ડ આરામ કરો”
- 30‑second rest music (random track from playlist)

### 🔄 Adaptive Gap Timing
- Gap duration automatically adjusts based on user performance
- Shrinks when user advances early
- Grows when user delays
- Configurable min/max limits

### 🧘 Clean Visual Interface
- Phase indicator
- Timer display
- Set & repeat counters
- Progress bars
- Pause / Resume / Next controls

### 🌐 Multilingual Support
- English
- Hindi
- Gujarati

### 📱 Works on Any Device
- Mobile
- Tablet
- Desktop
